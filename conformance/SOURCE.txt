Generated by tools/protocol_manifest.py against
crates/brain-protocol/src, which is the server's own definition of the
wire format. Refresh it the same way the corpus is refreshed — a
deliberate, reviewed step, never fetched in CI:

    ./tools/check_protocol.sh --refresh <brain-checkout>

The manifest records every struct (fields, types, serde attributes, and
declaration order, which is CBOR map order), every enum (variants,
discriminants, and whether it encodes as an integer or a tagged value),
and every opcode. tools/compare_rust.py checks the Rust SDK against it;
tools/compare_bindings.py checks Python and TypeScript against the Rust
SDK, which serde keeps tied to the wire.

THIS COMMIT IS NOT ON brain's main. 9609f199 sits on
`feat/capacity-durability-and-derivation-lane` (arc-labs-ai/brain-db#54), so
**no released server speaks this format yet** — the published 0.4.2 image does
not. What changed against the last released wire: ErrorResponse carries a plain
u16 code and u8 category, SchemaGetResponse has lost source_blob,
MemoryInspectResponse gained edge_total_count and edges_truncated, ErrorCode
traded thirteen per-field validation codes for ShardStorageFaulted and
UnrecoverableInternal, ErrorCategory gained OperatorIntervention, and fourteen
wire enums gained an Unknown sentinel. No struct, opcode or enum was added or
removed, so the verb surface is unchanged.

An earlier revision of this file was generated by running
tools/protocol_manifest.py directly against an uncommitted brain working tree
and said so, because `--refresh` refuses a dirty source. That vendor was
correct — re-running `--refresh` against 9609f199 reported +0 -0 ~0 against it,
which is the useful fact: the bytes were right, only the provenance was
unciteable. **Do not publish this SDK until #54 merges**, and re-run
`--refresh` against the merge commit then, so the manifest names a wire format
a released server actually speaks.

The parser reports anything it cannot read under "unparsed" rather than
dropping it, so a manifest with a non-empty unparsed list is not
trustworthy. It is currently empty for all 280 structs and 81 enums.

Generate it from a CLEAN checkout of that commit, never from a dirty
working tree. The manifest is a claim about what the server *ships*, and a
manifest built over uncommitted work pins the SDK to a wire format no
released server speaks. `--refresh` builds from `git archive <commit>`
and refuses a dirty protocol source, so the working tree cannot leak in.
