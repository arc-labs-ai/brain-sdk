PROVENANCE — reproducible pin.
This corpus is a verbatim copy of brain's committed conformance corpus at:

    3fd6868   (test(conformance): pin read-side response types in the corpus)

Verified reproducible: running brain's generator at that revision with
`BRAIN_CONFORMANCE_BLESS=1 cargo test -p brain-protocol --test conformance`
regenerates these exact bytes (zero diff). The bytes are the CBOR wire
format (post rkyv->CBOR migration), with 16-byte ids encoded as CBOR byte
strings even through Option/Vec (the P1-6 fix).

COVERAGE.
The corpus pins a representative payload for the handshake, the cognitive
verbs (encode/recall/forget/plan/reason), ENCODE_VECTOR_DIRECT, link,
the typed-graph create + read responses (entity create/get/list/resolve,
statement create/get/list, relation create/list), schema upload, QUERY,
MATERIALIZE_PROCEDURAL, TXN begin/commit/abort, GET_CAPABILITIES,
SUBSCRIBE_EVENT, the keepalive PONG/SERVER_PING frames, and the 9 error
categories. Each is round-trip + byte-exact verified in all three SDK
conformance suites.

Still unpinned (the SDKs do not implement these verbs yet, so there is
nothing to drift-guard): entity update/rename/merge/tombstone, statement
supersede/history/retract/tombstone, relation supersede/tombstone/
traverse, schema get/list/validate responses, QUERY explain/trace/text,
unsubscribe, and the admin surface. Add generator cases for those when
the SDKs gain the corresponding verbs.
